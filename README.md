# ผังสถานที่โรงเรียนศรียาภัย · Tonkla 26th

เว็บแผนที่แบบกดดูได้ของค่ายคณิตศาสตร์สัญจร ครั้งที่ 26 (11–12 ตุลาคม 2569) สำหรับ 3 ฝ่ายหลัก คือ **ฝ่ายพี่เลี้ยง ฝ่ายสวัสดิการ และฝ่ายพยาบาล** กดที่หมุดบนแผนที่เพื่อดูว่าตึกนั้นใช้ทำอะไร ช่วงเวลาไหน และแต่ละฝ่ายต้องทำอะไร หรือกดเลือกดูข้อมูลแยกตามฝ่ายก็ได้

> อัปเดตล่าสุด: 11 กันยายน 2569

## วิธีเปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร ไฟล์ทั้งหมดต้องอยู่ในโฟลเดอร์เดียวกัน ฟอนต์ Kanit / Sarabun โหลดจาก Google Fonts ถ้าไม่มีอินเทอร์เน็ตหน้าเว็บยังใช้ได้ แต่จะเป็นฟอนต์ของเครื่องแทน

## ความคืบหน้า

### ✅ เสร็จแล้ว
- แผนที่มีหมุด 6 จุด: อาคาร 1, 2, 3, 10, หอประชุม 11 และโรงอาหาร ชี้แล้วตึกสว่างขึ้นพร้อม tooltip แตะแล้วเปิดแผ่นรายละเอียด
- หน้ารายละเอียดตึก: สถานะการใช้งาน หน้าที่ของแต่ละฝ่ายในตึกนั้น และตารางกิจกรรม
- รูปอาคาร 10, หอประชุม 11 และโรงอาหาร แสดงในหน้ารายละเอียดตึก
- **ฝ่ายพยาบาล: จุดประจำตามช่วงกิจกรรม** เป็นไทม์ไลน์วันที่ 11 และ 12 ต.ค. ช่วงที่เอกสารไม่ได้ระบุจุดจะขึ้นว่า "เอกสารไม่ได้ระบุจุดพยาบาล"
- ฝ่ายพยาบาล: จุดประจำช่วงพักผ่อน (อาคาร 1, 2, 3) และชื่อประธาน / ผู้ช่วยประธานฝ่าย
- แยก CSS / JS ออกจาก `index.html`

### 🟡 ทำแล้วบางส่วน (รอข้อมูล)
- **ฝ่ายพยาบาล: ข้อมูลยา** มีกล่องพยาบาล ยาแก้เมา ลูกอมแก้เจ็บคอ แต่ยังไม่มีรายการยาที่เหลือ
- **ฝ่ายสวัสดิการ** ตอนนี้เป็นตารางเมนูอาหารที่ยังว่างทั้งหมด ยังไม่ได้ทำหน้ารายการสิ่งของสวัสดิการ

### ⏳ ยังไม่เริ่ม (รอข้อมูล)
- **ฝ่ายพี่เลี้ยง: พี่ประจำบ้าน 1–10** มีช่องรอไว้แล้ว แต่ยังไม่มีรายชื่อ

## ข้อมูลที่ต้องขอเพิ่ม

1. รายชื่อพี่เลี้ยงประจำบ้าน 1–10 พร้อมเบอร์ติดต่อ
2. ชื่อและช่องทางติดต่อของประธาน / ผู้ช่วยประธาน ฝ่ายพี่เลี้ยงและฝ่ายสวัสดิการ รวมถึงช่องทางติดต่อของฝ่ายพยาบาล
3. รายการสิ่งของสวัสดิการพร้อมจำนวน และเมนูอาหาร (ถ้าต้องการให้แสดง)
4. รายการยาทั้งหมด
5. สถานที่ของกิจกรรมที่ Action Plan ยังเป็น "-" โดยเฉพาะ Math Adventure (11 ต.ค. 09.50–11.35) และห้องชมรมบอร์ดเกมว่าอยู่ตึกไหน
6. จุดพยาบาลช่วงที่ยังไม่ระบุ: Math Adventure, พักกินข้าวกลางวันที่โรงอาหาร, Math Greed
7. รูปอาคาร 1, 2, 3 (ถ้าต้องการ)

## ปัญหาที่ทราบแล้ว (ยังไม่ได้แก้)

- ตารางหอประชุม 12 ต.ค. เขียนว่า "ลงทะเบียน**มัคคุเทศก์**ปฏิบัติงาน" แต่ Action Plan เขียนว่า "ลงทะเบียน**นิสิต**ผู้ปฏิบัติงาน"
- ตารางหอประชุม 11 ต.ค. เขียนว่า "กฎค่าย / **โต้**ค่าย" แต่ Action Plan เขียนว่า "**โค้ด**ค่าย"
- กิจกรรม 11 ต.ค. 12.35–12.50 (รวมตัว / อธิบาย Math Genius) อยู่ในตารางของทั้งหอประชุมและโรงอาหาร แต่ Action Plan ระบุว่าอยู่ที่โรงอาหาร
- ตารางกิจกรรมของแต่ละตึกบางช่วง**เดาสถานที่เอา** เพราะช่องสถานที่ใน Action Plan เป็น "-" เกือบทั้งหมด ควรยืนยันกับทีม
- ข้อมูลยาที่มีอยู่ และหัวข้อวันที่ 13 ต.ค. ในหน้าสวัสดิการ ไม่มีอยู่ในเอกสารต้นทางในโฟลเดอร์นี้ ควรยืนยันแหล่งที่มา (Action Plan มีแค่ 11–12 ต.ค.)
- ในไทม์ไลน์พยาบาล Break Time ที่อยู่กลาง Math Genius ให้พยาบาลอยู่ห้อง 1023 / 1026 ต่อ (อนุมานเอง)
- รูปอาคารแต่ละรูปมีขนาด 475–890 KB อาจโหลดช้าบนเน็ตมือถือ ถ้าเป็นปัญหาให้แปลงเป็น `.webp`

## วิธีแก้ไขข้อมูล

ข้อมูลทั้งหมดอยู่ใน `script.js`:

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `IMG` | path ของรูปแผนที่และรูปอาคาร |
| `DATA` | ข้อมูลแต่ละตึก: ตำแหน่งหมุด (`x`, `y` เป็น %), ชื่อ, หน้าที่ของแต่ละฝ่าย, ตารางกิจกรรม (`schedule`), รูป (`photo`) |
| `NURSE_TIMELINE` | ไทม์ไลน์จุดพยาบาลตามช่วงกิจกรรม block ที่ไม่มี `post` จะขึ้นว่า "เอกสารไม่ได้ระบุจุดพยาบาล" |
| `DEPTS` | หน้าข้อมูลแยกฝ่าย: ประธาน / ผู้ช่วยประธาน (`lead`) และเนื้อหาของฝ่าย (`render`) |

ถ้าจะเพิ่มตึกใหม่ ให้เพิ่ม object ใน `DATA` แล้วหมุดและปุ่มในรายการอาคารจะสร้างให้เอง
